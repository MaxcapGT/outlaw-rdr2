# Outlaw

A free mod manager for **Red Dead Redemption 2** on Windows.

- Website and live demo: https://outlaw-rdr2.pages.dev
- Download: see [Releases](https://github.com/MaxcapGT/outlaw-rdr2/releases/latest) and get `Outlaw-Setup-<version>.exe`

Outlaw updates itself: installed copies find new releases here, show the release notes and install over the current version without a reinstall. Your mods, profiles and settings are kept.

The installer is not code-signed yet, so Windows SmartScreen may warn on first run (More info, then Run anyway).

Outlaw is an independent fan-made tool. It is not affiliated with, endorsed by, or sponsored by Rockstar Games or Take-Two Interactive.
